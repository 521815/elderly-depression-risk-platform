# 共病轨迹协作包

负责人：共病与疾病轨迹研究组员

科学依据与方法边界见：

- `docs/25_共病轨迹接入_论文方法与组员协作.md`
- DOI: `10.1186/s12889-024-17890-7`

优先交付去标识化的“受试者-疾病-时间”长表。字段和填写规则见
`comorbidity_feature_template.csv` 以及同目录 `FIELD_NOTES.md`。

不要提交姓名、身份证号、病历原件、原始音频或未脱敏个体数据。

建议提交顺序：

1. 字段可用性报告：哪些字段能够从现有数据获得。
2. 疾病码映射表：论文 14 病种与项目 `chronic_*` 字段的对应关系。
3. 脱敏轨迹模板样例行。
4. 缺失、回忆偏倚和诊断来源说明。
5. 预先指定的轨迹假设，不得在看到验证结果后追加。
