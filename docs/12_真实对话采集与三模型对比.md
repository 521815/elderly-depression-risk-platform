# 真实对话采集与三模型对比

更新日期：2026-10-21

## 1 当前数据状态

项目现有真实数据包括 CHARLS 表格数据和 MPDD-Elderly 多模态数据，但没有已经配对完成的“真实老年对话 + 量表 + 多模态”研究会话。因此当前不能声称已完成真实对话外部验证。

本轮建立的是可执行的数据采集和评估管线，等真实脱敏会话导入后即可运行。

## 2 数据采集

模板：`data/research_dialogues/dialogue_sessions_template.csv`

必填字段：

- `subject_id`：受试者级脱敏编号；
- `session_id`：会话编号；
- `scale_name` / `scale_score`：量表名称与分数；
- `depression_label`：按预注册阈值得到的二分类标签；
- `transcript_json`：对话消息数组；
- `consent_code`：知情同意编号，禁止填写姓名。

可选字段包括年龄、性别、共病数、采集日期和 `mpdd_risk`。不得保存姓名、电话、地址、身份证号或未脱敏原始录音。

导入：

```bash
python scripts/43_import_research_dialogues.py \
  --input /path/to/sessions.csv
```

导入时自动提取：

- 睡眠、兴趣、情绪、躯体、认知、社交、无望/自责等症状标记；
- 症状持续时间；
- 功能影响；
- 安全风险；
- 用户发言轮数和文本长度。

## 3 受试者级切分

`src/elderly_depression/research_dialogues.py` 按 `subject_id` 划分训练、验证和测试，同一受试者的多条会话只进入一个集合，并在切分后检查三方受试者集合是否重叠。

真实数据接入后仍应预注册：

- 量表阈值；
- 训练/验证/测试比例；
- 是否使用 MPDD 多模态风险；
- 缺失值处理和模型类型。

## 4 三模型对比

脚本：

```bash
python scripts/44_compare_dialogue_models.py \
  --data data/research_dialogues/dialogue_sessions.csv
```

比较：

1. 量表 + 人口学；
2. 量表 + 人口学 + 对话结构化线索；
3. 量表 + 人口学 + 对话结构化线索 + MPDD 多模态风险。

输出指标包括：AUC、PR-AUC、灵敏度、特异度、F1、Brier、ECE 和阈值。模型使用低方差逻辑回归，验证集选阈值，测试集只评估一次。

## 5 流程烟测

由于当前没有真实配对会话，使用 `--demo` 生成模拟数据仅验证代码流程：

```bash
python scripts/44_compare_dialogue_models.py --demo
```

输出：

- `output/dialogue_three_model_report.csv`
- `output/dialogue_three_model_report.json`

demo 数据中的量表、对话和多模态信号共享同一个模拟风险源，因此指标会偏高，只能说明管线能运行，不能作为论文或临床证据。正式结果必须在导入真实脱敏会话后重新生成，并将 `clinical_evidence` 保持为真实数据标识。
