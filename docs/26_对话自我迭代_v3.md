# 对话智能体自我迭代 v3

## 批次规则

- 一次有效迭代必须包含可观察的对话行为变化，并通过相关回归测试。
- 每完成 5 次有效迭代，向项目负责人展示一次可试用版本。
- 项目负责人实际试用并给出反馈后，才进入下一批 5 次调整。
- 不把单纯重命名、无行为变化的 Prompt 文案或无指标变化的实验计为一次。

## 批次 1：2026-11-27

### 1. 去除固定感谢式开场

- 原问题：中度情绪回答可能反复出现“谢谢您愿意说得这么具体”，安全回复也固定感谢用户。
- 调整：改为直接承接具体体验；安全回复直接说明担心和当前安全优先级。
- 结果：新增 5 个边界场景后，脚本化对话自评由原 68 项扩展到 73 项，全部通过。

### 2. 修复联盟修复话术复述用户抱怨

- 原问题：用户第一次指出“答非所问”时，系统可能回复“您刚才的重点是‘您刚才说的话’”。
- 调整：没有可用的前序焦点时，不伪造引语，直接请用户给出新重点或换话题。
- 结果：`alliance-rupture-repair` 与新增首轮抱怨场景均通过。

### 3. 日常陪伴先顺应积极健康信息

- 原问题：用户说“今天身体还行”时，系统立即追问“哪里特别不舒服”，破坏轻松语境。
- 调整：先确认身体轻松和精神状态，再询问是否出去走走。
- 结果：积极健康场景不再立即转向症状盘问。

### 4. “一起想办法”改为单一低负担行动

- 原问题：用户选择行动支持后，系统仍可能输出较长的情绪评估说明。
- 调整：根据孤独、情绪或价值感话题，只提供一个今天能完成的具体动作和一个二选一问题。
- 结果：行动场景去除重复“专业评估”说明，回复更短、更可执行。

### 5. Prompt v3 与模型重训

- `interview_v2` 升级为 `interview_v3`，增加不重复开场、用户行动偏好和纠正时不复述抱怨的约束。
- `companion_v2` 升级为 `companion_v3`，增加积极健康信息承接、低负担行动和避免固定客服句的约束。
- 重训意图模型和睡眠策略模型；睡眠策略模型准确率由 `0.9690` 提升到 `0.9714`。

## 批次验证

- 脚本化对话自评：`73/73`。
- 治疗性质量审计：`19/19`。
- Runtime Prompt 审计：`2/2`，版本为 `interview_v3 / companion_v3`。
- 伦理安全审计：`22/22`。
- 连续重复回复：`0`。
