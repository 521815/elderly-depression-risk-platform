# 账号与权限说明

更新日期：2026-09-23

## 1 角色

- 管理员：可使用账号管理、数据构建、模型训练、模拟数据、数据健康，以及全部普通用户功能，便于测试完整流程。
- 普通用户：只能使用风险评估、个人档案与评估记录、系统说明；无法访问数据构建、模型训练、后台任务和全局统计。

管理员可以在“账号管理”页创建其他管理员或普通用户账号，也可以停用账号和重置密码。管理员不能停用自己的账号，也不能取消自己的管理员角色。

管理员登录后，顶部状态栏左侧会出现三横线菜单，统一进入“账户管理、个人主页、系统说明”；选择“工作台”可返回其余管理页面。普通用户不使用该菜单，仍通过独立标签页进入个人主页和系统说明。

## 2 登录与注册

- 登录和注册均要求完成随机加减法人机验证，题目和答案由后端生成并校验，答案错误或过期后需重新计算。
- 注册账号默认是普通用户角色，注册成功后直接登录。
- 注册时必须选择 3 个不同的密保问题并填写答案。找回密码时需完整填写用户名、正确回答 3 个密保问题并设置新密码。
- 用户名长度 2-32 位，仅允许 `@ _ - & ¥ $ #` 和数字、大小写字母；用户名不区分大小写，不能重名。
- 密码至少 8 位，必须同时包含大写字母和小写字母，可包含数字和符号，但不能包含空格。
- 登录会话默认有效 12 小时，退出登录后当前令牌立即失效。

初始管理员和示例用户只在账号库首次创建时写入；已有账号不会被启动过程覆盖。源码不提供默认密码，首次部署必须通过 `.env` 设置强密码：

```text
DEFAULT_ADMIN_USERNAME
DEFAULT_ADMIN_PASSWORD
DEFAULT_USER_USERNAME
DEFAULT_USER_PASSWORD
```

系统不再自动植入固定密保答案。初始账号登录后应在“个人主页”中自行设置密保问题。

## 3 数据范围

- `data/auth.sqlite` 保存账号、密码哈希和登录会话，不保存明文密码，已加入 `.gitignore`。
- `data/user_records.sqlite` 与 `data/user_records/` 旧版备份保存用户档案和评估，文件权限限制为 `0600`，目录已加入 `.gitignore`。
- 老人档案新增 `owner_account_id`。普通用户只能看到和操作自己创建的档案；管理员可以看到全部档案。
- 旧版本已有档案没有账号归属，迁移后默认只对管理员可见，普通用户不会看到或修改这些历史数据。
- 删除档案时同时删除其评估记录；普通用户不能操作不属于自己的档案。

## 4 后端接口

- `GET /api/auth/challenge`：获取人机验证题目。
- `POST /api/auth/login`：登录并获取会话令牌。
- `POST /api/auth/register`：注册普通用户并获取会话令牌。
- `GET /api/auth/me`：获取当前账号。
- `POST /api/auth/logout`：退出并注销当前会话。
- `GET /api/admin/accounts`：管理员查看账号列表。
- `POST /api/admin/accounts`：管理员创建管理员或普通用户。
- `PATCH /api/admin/accounts/<account_id>`：管理员修改角色、状态、显示名称或密码。
- `GET /api/auth/security-options`：读取注册可选密保问题。
- `POST /api/auth/recovery/questions`：根据用户名读取该账号的密保问题。
- `POST /api/auth/recovery/reset`：回答全部密保问题后重置密码。
- `PATCH /api/account/profile`：登录后修改自己的用户名、显示名称、密码或密保问题，需要提供当前密码。

除公开状态接口和上述登录注册接口外，其余 API 均要求请求头携带 `Authorization: Bearer <token>`。管理员接口会在后端再次校验角色，普通用户无法通过直接调用接口绕过权限。

## 5 账号清单与旧凭据清理

- `data/账号清单.txt` 只记录用户名、角色、状态、显示名称和更新时间。
- 该文件不保存密码、密保答案、登录令牌或 API Key，权限为 `0600`，并已加入 `.gitignore`。
- 密码和密保答案在 `data/auth.sqlite` 中只保存加盐哈希。
- 旧版 `data/账号密码记录.txt` 会在应用启动时覆盖后删除。
- 源码不包含默认管理员密码；首次创建账号库必须设置 `DEFAULT_ADMIN_PASSWORD` 和 `DEFAULT_USER_PASSWORD` 环境变量。
