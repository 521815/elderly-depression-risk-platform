# 理论基线、相关研究与消融设计

日期：2026-11-10

目的：核对“理论约束 baseline + 多模态 + 微调”是否仍具有独立创新性，并固定后续实验的最低证据要求。当前结论基于 Crossref、OpenAlex、Semantic Scholar、arXiv 与 PubMed 的初步检索；正式投稿前仍需逐篇核对全文、补充参考文献并做系统检索记录。

## 2. 对创新点的结论

以下单独表述已经不足以作为创新点：

- 我们首次使用理论 baseline。
- 我们首次融合文本、语音和视频。
- 我们首次对模态做消融。
- 我们首次对心理筛查模型做微调。
- 我们首次把理论、数据增强和对话 Agent 结合。

目前仍可能成立的有限空白是：

1. 在受试者不重合的多个真实队列中，区分“源内同人级多模态增益”和“跨源概率层迁移”，并明确禁止把非配对数据当成同人多模态。
2. 将理论构念、Agent 主动补全信息和模态证据价值结合起来，回答“为了达到足够稳定的风险分层，最少需要询问什么、采集哪些模态”。
3. 在样本少于 200 的条件下，系统比较传统模型、冻结编码器、LoRA 和模态融合，报告校准、缺失模态和负结果，而不是只报告最高 AUC。

这些只是候选空白，正式投稿前必须继续做全文检索，确认是否有工作已覆盖“非配对多源”或“证据价值/采集成本”问题。

## 3. 建议的核心研究问题

> 在老年抑郁风险筛查中，理论约束的结构化评估是否优于纯数据驱动模型；在控制样本量、缺失模态和数据来源后，对话 Agent 及多模态信号能否提供稳定的增量证据？

该问题同时包含四类比较：

- 理论基线与传统机器学习的比较。
- 结构化量表与自由对话的比较。
- 单模态与多模态的比较。
- 冻结模型、轻量微调与传统模型的比较。

## 4. 基线模型

基线与消融必须在相同标签、相同受试者切分和相同可用输入下比较。

| 编号 | 模型 | 目的 |
|---|---|---|
| B0 | 训练集患病率 | 最低参考线 |
| B1 | 年龄、性别、教育 | 人口学基线 |
| B2 | 生物心理社会理论变量，不含直接抑郁量表 | 检验理论构念本身 |
| B3 | B2 + 14 种静态慢病状态 + 认知变量 | 检验静态共病与认知增量 |
| B3T | B3 + 波次可观察的共病轨迹 | 检验疾病顺序和病程时间的增量 |
| B4 | B3 + 随机森林 | 静态变量下的非线性模型对照 |
| B4T | B3T + 随机森林 | 轨迹变量下的非线性模型对照 |
| B5 | 文本或结构化访谈单模态 | 语言贡献 |
| B6 | 音频单模态 | 声学贡献 |
| B7 | 面部/视频单模态 | 视觉贡献 |
| B8 | 早期特征融合 | 联合表示是否有效 |
| B9 | 后期概率融合 | 缺失模态下是否稳健 |
| B10 | 冻结预训练编码器 + 线性头 | 低样本迁移基线 |
| B11 | LoRA/Adapter 微调 | 微调是否真正优于冻结模型 |
| B12 | 理论约束 + 多模态 Agent | 最终拟议模型 |

如果 CHARLS 与多模态队列受试者不重合，则 CHARLS 基线在队列内部训练和验证，
不能把 CHARLS 的 B2-B4T 原始行与多模态 B5-B9 拼接。B3T/B4T 的轨迹特征
只能使用当前及既往波次，后续诊断不得回填到早期预测。

## 5. 消融实验

### 5.1 模态贡献

- 文本、音频、视频各自单独训练。
- 两两组合与三模态完整组合。
- 完整模型逐一移除一种模态。
- 不同模态缺失率：25%、50%、75%。
- 早期融合与后期融合对照。
- 手工临床特征与通用深度特征对照。

### 5.2 理论变量贡献

- 删除整个理论模块。
- 分别删除易感因素、压力因素、保护因素。
- 理论变量与量表变量互为消融。
- 固定随机种子后比较 ΔAUC、ΔPR-AUC、ΔBrier 和校准斜率。

### 5.3 微调贡献

- 预训练特征直接推理。
- 冻结编码器 + 线性分类头。
- 只训练最后几层。
- LoRA/Adapter。
- 全参数微调，仅在样本量允许时进行。

HiPAD 的低样本结果表明，全量微调可能改善二分类一致性，却破坏严重程度回归，且冻结 RoBERTa 反而更稳。因此本项目不能预设“微调一定更好”。

### 5.4 数据增强贡献

- 只用真实训练集。
- 真实训练集 + 模拟训练集。
- 只用模拟训练集。
- 真实验证集和测试集始终不混入模拟数据。
- 同时报告分布门槛、下游性能和校准变化。

### 5.5 跨源与缺失模态

- 各队列独立模型。
- 概率校准后的源间迁移。
- 领域适配与不适配的对照。
- 完整模态与缺失模态模型。
- 同一模型在年龄、性别、共病亚组中的性能。

## 6. 评价指标

不能只看 Accuracy 或 AUC。所有主要比较至少报告：

- Accuracy、Balanced Accuracy、F1。
- 固定特异度下的灵敏度。
- AUC、PR-AUC。
- Brier、ECE、校准斜率与截距。
- 决策曲线净获益。
- Bootstrap 95% 置信区间。
- 亚组性能与缺失模态性能。

## 7. 当前判断

“理论 + 多模态 + 微调”作为整体口号已经不够新，必须转化为可验证的比较问题。最现实的可发表贡献是：

1. 明确区分同人配对模态与非配对跨源证据。
2. 用理论基线、传统模型和冻结模型构成多层对照。
3. 通过模态、理论块、微调深度和增强策略的完整消融，回答多模态和微调究竟何时有增量。
4. 如果微调没有超过传统模型，应保留负结果，而不是删除不利实验。

下一步需要完成系统性数据库检索与全文核对，重点确认“非配对多源验证”“Agent 主动补全理论变量”“信息价值/采集成本”三个候选空白是否真的无人覆盖。

## 8. 首轮真实数据结果

首轮运行日期：2026-11-11。

### 8.1 CHARLS 理论基线

CHARLS 采用按 `id` 分组的 5 折交叉验证，同一受试者的不同波次不会跨训练折和验证折。`cesd_score`、`depression`、`wave` 和 `id` 均未进入特征，避免直接标签泄漏。

| 基线 | 变量 | AUC | PR-AUC | Brier | F1 |
|---|---|---:|---:|---:|---:|
| B0 | 训练折患病率 | 0.500 | 0.368 | 0.233 | 0.000 |
| B1 | 人口学 | 0.615 | 0.460 | 0.240 | 0.508 |
| B2 | 生物心理社会环境与健康变量 | 0.820 | 0.723 | 0.173 | 0.683 |
| B3 | B2 + 慢病明细 + 认知变量 | 0.827 | 0.732 | 0.169 | 0.686 |
| B3T | B3 + 波次共病轨迹 | 0.828 | 0.734 | 0.169 | 0.688 |
| B4 | B3 + 随机森林 | 0.827 | 0.732 | 0.164 | 0.679 |
| B4T | B4 + 波次共病轨迹 | 0.827 | 0.731 | 0.164 | 0.677 |

分组 Bootstrap 结果显示：

- B2 相对 B1 的 AUC 增量为 `+0.205`，95% CI `0.197–0.213`。
- B3 相对 B2 的 AUC 增量为 `+0.0068`，95% CI `0.0055–0.0079`。
- B4 相对 B3 的 AUC 增量为 `+0.0004`，95% CI `-0.0010–0.0019`，没有可确认的排序提升；Brier 有所改善。
- B3T 相对 B3 的 AUC 增量为 `+0.00074`，95% CI `0.00021–0.00121`；
  PR-AUC 增量为 `+0.00110`，Brier 降低 `0.00039`。增量方向存在，但幅度很小。
- B4T 相对 B4 的 AUC 增量为 `-0.00051`，95% CI `-0.00147–0.00041`；
  PR-AUC 下降 `0.00166`，Brier 增加 `0.00004`，没有稳定提升。

结论：理论核心变量提供了最大增量，慢病明细和认知变量带来小幅增量。基于现有
四轮疾病状态构造的波次观察轨迹仅在逻辑回归中带来极小增量，在随机森林中未复现，
因此当前不能把共病轨迹写成稳定的主模型突破。后续取得首次确诊年龄并补齐疾病
转移数据后，应重新运行 B3/B3T/B4/B4T。

### 8.2 MPDD 同人级模态消融

MPDD 使用官方 `label2`，87 名有标签受试者先按受试者聚合片段特征，再执行 5 折 × 5 次受试者分组交叉验证。所有模态组合共享相同受试者切分。

关键结果：

| 模态组合 | AUC | PR-AUC | Brier | F1 |
|---|---:|---:|---:|---:|
| 面部 | 0.556 | 0.484 | 0.300 | 0.379 |
| 音频 | 0.552 | 0.456 | 0.288 | 0.320 |
| 步态 | 0.587 | 0.490 | 0.258 | 0.414 |
| 人格 | 0.596 | 0.486 | 0.269 | 0.411 |
| 面部 + 音频 + 人格 | 0.624 | 0.530 | 0.214 | 0.290 |
| 面部 + 步态 + 人格 | 0.628 | 0.522 | 0.216 | 0.364 |
| 四模态完整模型 | 0.627 | 0.531 | 0.212 | 0.333 |

与四模态完整模型相比：

- 删除音频后 AUC 变化 `+0.0003`，Holm 校正后 `P=1.000`；Brier 变差 `0.0034`，同样不显著。
- 删除步态后 AUC 变化 `-0.0031`，Holm 校正后 `P=1.000`。
- 仅保留面部 + 人格时 AUC 降低 `0.0089`，但校正后仍不显著。
- 四模态模型的 Brier 显著优于多数单模态或双模态组合，但没有显著优于三个最优三模态组合。

结论：当前 87 人数据不支持“加入音频或多模态数量越多，分类排序一定更好”。四模态模型的优势主要体现在概率质量，而不是统计上明确的 AUC 提升。

### 8.3 微调边界

本轮没有把 PCA 或随机森林包装成“大模型微调”。在只有 87 名有标签受试者且缺少独立锁定外部测试集的情况下，端到端全参数微调的结论不可估计。后续至少需要同人配对的独立数据，才能公平比较：

- 冻结编码器 + 线性分类头
- 仅训练最后几层
- LoRA/Adapter
- 全参数微调

### 8.4 跨源结论

- CHARLS：13,084 名受试者，有量表、共病、功能和社会变量，没有音视频和步态。
- MPDD：87 名有官方标签的老年受试者，有配对的面部、音频、步态、人格，但当前派生表缺少统一的人口学、共病和睡眠字段。
- CMDC：78 名混合成人受试者，有文本、语音和视觉，但不是老年专属数据。

三者受试者不重合，且标签来源不同。因此本轮只允许源内验证和证据可用性审计，不进行跨源个体级特征拼接。首轮结果文件位于 `output/incremental_validation/`。
