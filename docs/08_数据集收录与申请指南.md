# 公开数据集收录与申请指南

更新日期：2026-09-03

用途：面向导师汇报与后续真实样本扩展。本页只收录官方入口、免费程度与申请流程，不包含 MPDD 原始数据或任何派生数据；涉及 MPDD 时仍以 `docs/07_MPDD数据使用合规.md` 的红线为准。

## 1 一句话结论

- 当前真实数据家底已经能支撑 CHARLS 表格基线（受试者级 AUC 约 0.83）和 MPDD 多模态基线（有标签 87 人，受试者级融合 AUC 约 0.70）；真实样本缺口主要在“带 PHQ-9 标签、中文、老年或同年龄段、音视频 + 步态”的多模态样本。
- 公开可直接收录的采用项：CLHLS + HRS + ELSA + SHARE。CLHLS 是中国老年纵向调查，用于 CHARLS 表格模型的真实样本外验证；HRS、ELSA、SHARE 是跨文化老年队列，用于上海等多元城市场景下的跨文化敏感性分析。公开免费数据中没有面向中国老年人群的音视频多模态真实样本。
- 近期申请优先级建议：MPDD-Young / MPDD-AVG-2026 同源官方数据 > CLHLS 表格外部验证 + HRS/ELSA/SHARE 跨文化验证 > MODMA 中文生理/语音补充。CMDC 已按 EULA 获取并接入为独立中文多模态外部验证。
- DAIC-WOZ、E-DAIC、D-Vlog 等需申请语料不是中国老年样本，不能冒充独立外部验证；只适合作为预训练特征来源、领域泛化分析或方法学参考。

## 5 申请材料准备清单

- 申请人主体：建议仍由导师以全职教师/研究员身份提交，学生不直接以个人名义申请。
- 材料内容：研究题目与目的、所属单位、数据使用范围、参与成员名单、申请的子集名称、拟发表的成果类型、数据保管与删除承诺。
- 合规承诺：仅学术研究；不商用；不向课题组外再分发；不披露个人可识别信息；验收后按数据方要求删除。
- 对 MPDD 系列：每次申请新子集（Young、AVG-2026）都先问清“是否覆盖已有许可，还是需要另签协议”，并保留数据方书面确认。

## 6 收到数据后的接入检查

- 先建立变量/标签口径映射表：PHQ-9、CESD-10、GDS、SDS、HAMD 不能混用；二分类阈值、严重度三分类口径逐项记录。
- 检查人群与采集协议是否可合并：同一采集协议才可做合并训练；跨协议数据先做分布诊断，再决定是迁移学习还是独立验证。
- 外部验证声明：只有与训练样本独立且协议可比的数据能称为外部验证。CLHLS 与 CHARLS 均为中国老年表格队列，映射后可用于表格模型跨队列验证；HRS、ELSA、SHARE 面向老年人群但为外国样本，只写“跨文化敏感性分析”，不冒充上海本地前瞻验证；跨语言、跨平台、非老年数据只写“领域泛化/预训练”。
- 工程落地：新数据先落到独立目录，禁止覆盖 MPDD 官方目录；更新 manifest 与数据健康页，记录新增来源。

## 7 按未来真实样本量的模型路线

### 低样本路线（现状：MPDD-Elderly 87 有标签 + CHARLS 表格）

- 维持受试者级重复交叉验证、概率校准与阈值选择，不引入大参数深度模型。
- 用特征筛选、正则化集成与多算法对比降低过拟合；当前随机森林/XGBoost/逻辑回归的 CHARLS AUC 均约 0.83，融合模型受试者级 AUC 约 0.70，先把每个报告口径钉死。
- 明确“模拟组只用于训练侧研究”，验证与测试始终使用真实数据。

### 中样本路线（同源补充：MPDD-Young 或 MPDD-AVG-2026 更新版）

- 若拿到同协议样本，可做 5 折×多次受试者级合并训练，并新增两年龄组对比、跨年龄组泛化与人格/共病亚组分析。
- 每多一折真实样本都应重跑现有受试者级报告，看 AUC/校准曲线是否随样本增加变稳。
- 若样本量达到约 200+，可尝试轻量级融合头（浅层 MLP/线性层 + 预训练特征），但仍不建议从零训练大模型。

### 高样本路线（同源补充 + 中文申请数据到位）

- MPDD-Young / MPDD-AVG-2026：同源合并训练，可做两年龄组对比与跨组泛化；若样本量达到约 200+，可尝试轻量级融合头。
- CMDC 已用于中文访谈音视频外部验证和领域适配；MODMA 等中文数据到位后只作为生理/语音补充。
- CHARLS + CLHLS + HRS/ELSA/SHARE：CLHLS 用于中国老年跨队列真实样本外验证；HRS/ELSA/SHARE 用于跨文化敏感性分析；均不能与多模态训练样本混用。
- 长期路线：在导师确认伦理与知情同意后，把桌面系统作为科研筛查工具积累随访队列，获得真正的老年中文前瞻标签。
