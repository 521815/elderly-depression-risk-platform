实际采用的是设计原则，不复制帖子中的具体界面。

## 落地的设计原则

### 信息层级

- 页面只保留一个主标题层级，减少重复眉题和卡片标题。
- 功能导航从主画布移入左侧栏，并按筛查、研究数据、模型证据、系统运行分组。
- 顶部只显示当前工作区、系统就绪状态和全局菜单。
- 主区先显示任务，再显示设置和详细表单。

### 留白与布局

- 去掉顶部 13 个等权小格，主区获得连续宽度。
- 风险评估改为一体化工作板：标题、证据输入和步骤条属于同一结构。
- 筛查设置合并成一个面板，不再用三个零散卡片切碎页面。
- 移动端将记录页左右栏、风险页主栏和双图布局改为纵向排列。

### 动效

- 页面进入：`300-420ms`，上移 `7-8px`，只执行一次。
- 悬停：按钮上浮 `1px`，侧栏导航水平移动 `2px`。
- 按压：缩放到 `0.985`，避免突然跳变。
- 弹出菜单：`160ms` 缩放和透明度过渡。
- 主视觉证据项按 `45ms` 间隔依次进入。
- 输入焦点、标签页、指标卡和聊天消息均有短过渡。
- 所有动画都遵循 `prefers-reduced-motion`。

### 视觉语言

- 墨绿侧栏、灰白研究画布、深青主操作和暖金属色强调。
- 侧栏功能保留中文名称与英文代码的双层标签，当前模块使用暖金属底色和轻微抬升。
- 用户消息使用深青底与右侧暖金边，助手消息使用浅底与左侧青绿边，对话双方更容易区分。
- 所有二级章节标题增加短线索引；图表、数据表和 JSON 结果增加统一承载面，避免数据页出现裸露白块。
- 数据健康页将 Warning 列表收成“问题摘要 + 检查明细”，避免整屏黄色提示块竞争注意力。
- 不使用持续闪烁、背景光斑、装饰性渐变或满屏玻璃效果。
- 风险颜色只用于安全、风险和警告语义。

## 验证

- 桌面 `1440×900` 和桌面 App 常用 `1280×820` 窗口完成实际渲染检查。
- 窄屏 `390×844` 检查主区、菜单和用户记录页，无横向溢出。
- 用户记录页在移动端从两栏切换为单栏。
- 顶部菜单在移动端提供功能模块选择入口。
- 完整测试 216 项通过，`compileall` 和 `git diff --check` 通过。
