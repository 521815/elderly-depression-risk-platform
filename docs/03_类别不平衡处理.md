# 类别不平衡处理

CHARLS 中 CESD-10 >= 10 的比例通常明显低于非抑郁；MPDD 训练集中 PHQ-9 >= 8 的正样本为 28/87。项目按论文常用方法做“数据层 + 算法层 + 评估层”三部分处理。

## 1. 数据层

- SMOTE / SMOTE-ENN / SMOTE-Tomek / ADASYN：只对训练集合成少数类样本，绝不过采样测试集。
- 随机欠采样/过采样：作为简单基线，配合完整交叉验证防止信息泄漏。
- 多折分层划分：`StratifiedKFold` 保持各折类别比例一致。

## 2. 算法层

- `class_weight='balanced'`（Logistic / RandomForest）。
- XGBoost `scale_pos_weight = 负样本数 / 正样本数`。
- 焦点损失（Focal Loss）：对易分类负样本降权，适合 MPDD 深度多模态模型。
- 多任务学习：MPDD 把人格评估作为辅助任务，缓解样本少、抑郁类别失衡带来的过拟合。

## 3. 评估层

- 不只报告 Accuracy：重点看 Precision、Recall、F1、AUC、PR-AUC。
- 用验证集选择分类阈值（Youden J 或最大化 F1），而不是固定 0.5。
- 概率校准（Platt/Isotonic），让“抑郁概率”可用于实际筛查。

## 5. 已落地的对比实验

当前项目会把 7 种策略跑成一张对比表，并额外保存 PR-AUC、灵敏度、特异度、平衡准确率和 Brier 分数：

- `output/imbalance_comparison.csv`：前端展示用精简结果
- `output/imbalance_paper_report.csv`：论文可用的完整指标
