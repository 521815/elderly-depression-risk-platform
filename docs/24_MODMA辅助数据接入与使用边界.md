# MODMA 辅助数据接入与使用边界

更新日期：2026-11-16

## 1 结论

MODMA 已由导师完成申请并确认可用于本项目。该数据集纳入项目的定位是“跨年龄段中文临床抑郁辅助数据”，用于语音预训练、跨域迁移和鲁棒性分析，不作为老年主模型验证集，也不代表社区老年人的真实分布。

## 2 授权与存储

- 申请主体：项目导师。
- 使用状态：导师已确认可用的学术研究数据。
- 正式 EULA 编号、签署日期和申请邮箱由导师提供的文件归档到受限材料目录，不写入 Git 仓库。
- 原始音频、EEG、受试者信息表和派生特征统一存放于 `data/modma/`，继续由 `data/*` 忽略规则排除。
- 原始数据和派生数据不上传 GitHub、公开网盘、微信群或第三方大模型。
- 对外只报告聚合统计、模型指标和不含受试者编号的图表。

## 3 数据构成

官方说明和受试者信息表显示：

| 数据部分 | 样本 | 说明 |
|---|---:|---|
| 语音 | 52 人，23 名 MDD、29 名 HC | 每人 29 段，共 1,508 段；访谈、阅读、词语朗读和图片描述 |
| 3 导联静息 EEG | 55 人 | 26 名 MDD、29 名 HC；适合轻量可穿戴探索 |
| 128 导联静息 EEG | 53 人 | 24 名 MDD、29 名 HC |
| 128 导联 ERP EEG | 53 人 | 点探测任务，与当前风险筛查链路关系较弱 |

受试者信息表包含 PHQ-9、GAD-7、PSQI、CTQ-SF、LES 和 SSRS，可用于睡眠、焦虑、社会支持和压力因素的辅助分析。

## 4 人群与标签边界

- 纳入年龄为 18 至 55 岁。
- 52 名语音受试者平均年龄约 31.3 岁，中位数约 29.5 岁，最大 52 岁。
- 标签为精神科医生依据 MINI/DSM-IV 诊断的 MDD 与健康对照，不等同于 CESD-10 或 PHQ-9 阈值筛查标签。
- MODMA 与 CHARLS、MPDD、CMDC 的受试者不重合，不能按行拼接成个体级多模态样本。
- MODMA 不是老年专属数据集，不能计入“老年外部验证”。

## 5 允许用途

1. 使用语音数据训练或预训练中文抑郁语音编码器。
2. 将 MODMA 作为源域，研究向 MPDD 老年语音目标域的迁移。
3. 进行跨年龄段、跨录音设备和跨任务类型的鲁棒性分析。
4. 在 3 导联静息 EEG 上开展轻量可穿戴探索。
5. 使用 PHQ-9、PSQI、GAD-7、SSRS 等量表研究语音和临床量表之间的关系。
6. 作为独立章节报告“辅助数据”，不与老年主队列结果混表。

## 6 禁止用途或表述

- 不将 MODMA 表述为老年抑郁数据集。
- 不将 MODMA 指标表述为社区老年人的临床性能。
- 不把 MDD 临床诊断与 CESD-10 高风险机械等价。
- 不按 WAV 片段随机切分；所有训练、验证和测试必须按 `subject_id` 分组。
- 不把 EEG、语音与 MPDD 面部、步态或 CHARLS 表格随机配成同一个人。
- 不向第三方大模型发送原始音频、转写或受试者量表。

## 7 实施阶段

### 阶段 A：语音数据审计

- 校验 52 个受试者目录和 1,508 个 WAV 文件。
- 检查每人是否恰有 1 至 29 号录音。
- 检查 WAV 可读性、采样率、通道数、时长、静音比例和文件损坏。
- 与受试者信息表核对 ID、MDD/HC 标签和年龄。
- 生成不含原始音频的审计 JSON。

### 阶段 B：语音特征与源内基线

- 提取可复现的声学特征，优先使用 openSMILE/eGeMAPS 或项目已安装的预训练语音嵌入。
- 按受试者聚合 29 段语音，分别保留访谈、阅读和图片描述的任务类型。
- 使用重复分层分组交叉验证。
- 报告 AUC、PR-AUC、灵敏度和特异度、F1、Brier 和校准。

首轮可复现基线已完成：

| 项目 | 结果 |
|---|---:|
| 分析受试者 | 52 人 |
| 可读语音片段 | 1,503 段 |
| 总语音时长 | 约 7.19 小时 |
| 特征 | MFCC 13 维均值/标准差、能量、过零率、频谱质心、带宽、滚降、平坦度和静音比例 |
| 分类器 | 标准化 + L2 逻辑回归，C=0.1，类别平衡，阈值 0.5 |
| 验证 | StratifiedGroupKFold，5 折重复 5 次，按 subject_id 分组 |
| AUC | 0.667 ± 0.156 |
| PR-AUC | 0.706 ± 0.155 |
| 平衡准确率 | 0.648 ± 0.125 |
| F1 | 0.550 ± 0.233 |
| Brier | 0.232 ± 0.060 |
| ECE | 0.269 ± 0.082 |

这组结果说明 MODMA 语音中存在可检测的抑郁相关信号，但当前手工声学特征、单中心和 52 人样本不足以支撑直接接入产品风险评分。较高的 ECE 也说明概率校准是下一步必需工作。

### 阶段 C：向老年队列迁移

- 设计“无 MODMA 预训练”和“MODMA 预训练”两套同结构模型。
- 仅在 MPDD 训练折上微调。
- 在固定 MPDD 验证或锁定留出集上比较增量。
- 如果 AUC 没有改善，保留 Brier、校准或缺失模态鲁棒性方面的结果；如果所有指标均无改善，则不接入主模型。
- 当前首轮源内基线 AUC 约 0.667，先作为辅助可行性结果；需要通过预训练语音嵌入和 MPDD 迁移实验证明增量后，才考虑进入主模型。

### 阶段 D：轻量 EEG 探索

- 先使用 3 导联静息 EEG。
- 128 导联静息 EEG 仅作为稳健性复核。
- 128 导联 ERP 暂不下载、不进入当前产品流程。

## 8 质量门槛

- 元数据 ID 覆盖率必须为 100%，无法映射的音频不进入训练。
- 每人 29 段中缺失比例超过 20% 的受试者需要单独标记。
- 损坏或不可读取的音频不得用零信号静默替代。
- 同一受试者只出现在一个切分折中。
- 训练集重采样只能作用于训练折。
- 外部迁移结果必须同时报告无辅助数据基线。
- 任何前端展示都要标注“MODMA 为跨年龄段临床辅助数据”。
