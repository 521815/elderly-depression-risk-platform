# 数据说明

## CHARLS

使用 `Harmonized CHARLS/H_CHARLS_D_Data-cleaned/clean_H_CHARLS_D_Data.dta`。

宽表：每个 `id` 一行，`r1-r4` 代表 2011/2013/2015/2018 四个调查波次。

构建后的标准字段：

```text
id, wave, age, gender, education, marital_status,
self_rated_health, sleep_quality, adl_score, mobility_score,
vigorous_activity, moderate_activity, light_activity,
smoker, drinker, income_earn, income_pension, social_work,
chronic_hypertension, chronic_diabetes, chronic_cancer,
chronic_lung, chronic_heart, chronic_stroke, chronic_psychiatric,
chronic_arthritis, chronic_dyslipidemia, chronic_liver,
chronic_kidney, chronic_digestive, chronic_asthma, chronic_memory,
comorbidity_count, cesd_score, depression
```

标签定义：`depression = 1` 当 `cesd_score >= 10`。

注意：部分波次缺失较多，脚本只保留目标变量和目标特征至少有一个有效值且有 CESD 分数的记录；缺失特征保留为 NaN，训练时按中位数/众数填充。

## MPDD

参考《Multimodal Depression Assessment Framework Integrating Personality and Gait for Older Adults With Medical Conditions》：

- 本机已接入 110 名老年人：训练集 87 人、测试集 23 人。
- 模态：面部视频、语音、步态、人格；标签：PHQ-9 分数 + 二分类/三分类 + 人格描述。
- 经官方许可协议申请获得的是提取后的特征：OpenFace、OpenGraphAU、表情、ResNet-50、OpenSmile、Mel、Wav2Vec、TSFEL 步态特征。
- 使用要求：MPDD 数据仅限学术研究，不得商用、不得再分发或向课题组外提供，具体流程与红线见 `docs/07_MPDD数据使用合规.md`。

官方特征已放在 `data/mpdd/`，可直接用 `scripts/02_build_mpdd_dataset.py` 聚合成每个样本一行的 CSV：

```text
subject_id, fold, phq9_score, hamd_score, label2, label3,
face_* ... audio_* ... gait_* ... personality_* ...
```

当前聚合结果保存在 `data/mpdd_features.csv`，包含语音、面部、步态、人格四类模态，
其中 `hamd_score` 与 `phq9_score` 同时写入，默认按 `>= 8` 生成抑郁风险二分类。

## CMDC

- 78 名混合成人受试者：健康对照 52 人、MDD 26 人。
- 每人 12 道半结构化中文访谈问题，包含原始音频、转写、文本嵌入、语音嵌入、openSMILE 声学和面部视觉特征。
- 本项目只保留去标识化的受试者级数值特征，原始音频和转写不进入项目目录。
- 文本覆盖 77 人、视觉覆盖 45 人、语音覆盖 78 人、全模态完整病例 44 人。
- CMDC 不是老年专属数据集，且缺少结构化年龄、性别、共病和量表分数，只用于中文多模态外部验证和领域适配。
- 使用受 CMDC EULA 约束，仅限非商业学术研究，禁止再分发或转交归档密码。

完整接入、评估协议和合规说明见 `docs/21_CMDC中文多模态外部验证接入.md`。
