# 总体方案

## 1. 问题定义

输入：一段与老年人的半结构化对话（文本/音频/视频）、可选的量表作答结果、人口学与共病信息。

输出：抑郁风险概率（0-1）、风险等级（低/中/高）、主要风险因素、建议量表或随访动作。

## 2. 系统模块

### 2.1 对话与量表模块

- 大模型负责自然对话，围绕睡眠、兴趣、情绪、躯体不适、社会活动等维度提问。
- 对话中动态调用 CESD-10、PHQ-9、GDS-15；MPDD 当前标签使用 PHQ-9，HAMD-24 保留为量表计分接口。
- 量表结果单独进入“量表风险分”，与语言内容解耦，避免模型把重复问题当成新的情绪信号。

### 2.2 语言风险特征

- 情绪倾向：正面/负面词密度、否定词、第一人称使用率。
- 抑郁语义线索：无价值感、兴趣减退、睡眠差、自杀意念等话题命中。
- 会话行为：平均句长、停顿/犹豫标记、重复表达、回答长度。
- 后续可替换为中文预训练情感模型或 LLM 结构化抽取。

### 2.3 表情与语音特征（MPDD）

- 官方提取特征已接入本机，训练集 87 人、测试集 23 人。
- 面部：OpenFace AU、OpenGraphAU、表情概率、ResNet-50 深度特征。
- 音频：OpenSmile 声学特征、Mel 频谱、Wav2Vec。
- 步态：TSFEL 提取的时间/频域/统计特征，重点保留速度、步幅、节律相关特征。
- 人格：BigFive-10，作为辅助任务和多模态输入。

### 2.4 表格风险模型（CHARLS）

- 标签：CESD-10 >= 10 判定为抑郁高风险。
- 特征：年龄、性别、婚姻、教育、收入、睡眠、ADL/IADL、认知、吸烟饮酒、自评健康、13 类慢性病及其共病数。
- 模型：Logistic / RandomForest / XGBoost，用 LASSO 特征筛选和 SHAP 解释。

### 2.5 中文访谈外部验证（CMDC）

- 数据集为 78 名混合成人受试者，健康对照 52 人、MDD 26 人，每人 12 道半结构化访谈题。
- 文本、语音深度嵌入、openSMILE 声学和面部视觉特征独立聚合到受试者级，严禁按问句随机切分。
- 主外部验证模型采用文本＋语音，视觉作为完整病例子集敏感性分析。
- CMDC 不是老年专属队列，且缺少结构化年龄、性别、共病和量表分数，因此不进入当前老年风险主评分。
- 该数据用于中文访谈领域适配、外部验证和后续多模态编码器预训练。

### 2.6 融合与校准

- 表格模型输出先做概率校准（Platt 或 Isotonic）。
- 多模态模型输出概率，文本模型输出概率，量表分转换概率。
- 最终采用加权/Stacking 融合，并使用验证集阈值选择（Youden J 或最大化 F1）。

## 3. 实验设计

- CHARLS：分层抽样训练/验证/测试，时间外验证（用后一波次验证前一波次）。
- MPDD：按官方提供的数据构建（87 训练 / 23 测试），以 utterance 为样本、被试为分组单位做重复分层交叉验证，报告 Accuracy、Precision、Recall、F1、AUC、PR-AUC、Brier；另做 label3 三分类、PHQ-9 回归和测试集预测导出。
- CMDC：按受试者聚合 12 个问题，重复分层 K 折完全按 `subject_id` 切分；报告 AUC、PR-AUC、平衡准确率、灵敏度、特异度、F1 和 Brier。全模态结果只来自同时具备四类特征的完整病例。
- 对比：单模态 vs 多模态、人格辅助任务 vs 无辅助任务、是否加入步态。
- 消融：是否加入共病信息、性别、年龄分组。

## 4. 伦理与落地

- 本项目用于科研筛查与风险提示，不替代临床诊断。
- 已获取数据按 MPDD/CHARLS/CMDC 各自协议使用，后续新增数据仍按协议申请和脱敏。
- MPDD 数据仅限学术研究，禁止商用与再分发；官方协议、申请流程与本地操作红线见 `docs/07_MPDD数据使用合规.md`。
- CMDC 仅限非商业学术研究，禁止再分发原始访谈、公开音频或转交归档密码；合规说明见 `docs/21_CMDC中文多模态外部验证接入.md`。
- 真实可识别数据的采集、保存和科研使用必须另行取得伦理审批与知情同意，不以本系统工程措施代替伦理审查。
- 第三方大模型调用默认关闭，必须单独同意；发送前执行姓名、住址、电话、证件号和邮箱脱敏。
- 密码与密保答案只保存哈希，不保留明文凭据；本地数据库权限限制为 `0600`。
- 输出必须包含“非诊断”说明，并提供精神卫生求助渠道。
- 完整的隐私、安全、公平性、人工复核和事件响应要求见 `docs/19_科研工程伦理与数据治理.md`。
