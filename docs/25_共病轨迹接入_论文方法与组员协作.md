# 共病轨迹接入：论文方法、当前实现与组员协作边界

## 1. 直接依据

Chen J, Zhang F, Zhang Y, et al. Trajectories network analysis of chronic
diseases among middle-aged and older adults: evidence from the China Health and
Retirement Longitudinal Study (CHARLS). BMC Public Health. 2024;24:559.

DOI: `10.1186/s12889-024-17890-7`

该研究使用 CHARLS 2011、2013、2015、2018 四轮数据中的 15,895 名受试者，
分析 14 种慢性病的发生顺序、疾病对风险和网络位置。论文的主要发现是：

- 关节炎位于疾病轨迹网络起点。
- 高血压、心脏病、血脂异常和消化系统疾病位于网络中心。
- 卒中、记忆相关疾病和糖尿病位于网络末端。
- 前两病种的中位间隔约 9.5 年，第二到第三个病种缩短至约 5.1 年。
- 论文中的“情绪与精神问题”未进入显著疾病网络，不能据此宣称抑郁位于共病网络中心。

## 2. 当前系统如何接入

新增 `src/elderly_depression/features/comorbidity_trajectory.py`，从现有
`data/charls_standardized.csv` 的 `id`、`wave` 和 14 个 `chronic_*` 字段派生
共病轨迹特征。

当前特征包括：

- 当前慢病负担。
- 当前波次新观察到多少个病种。
- 首次观察时的慢病负担，以及是否只有一个明确首病。
- 首次观察到慢病后的随访年数。
- 第一到第二个不同病种之间的时间间隔。
- 首个病种之后新增的病种数量及平均进展速度。
- 当前中心疾病负担：高血压、心脏病、血脂异常、消化系统疾病。
- 当前末端疾病负担：卒中、记忆相关疾病、糖尿病。
- 首病是否为关节炎。
- 关节炎→高血压、关节炎→高血压→血脂异常/心脏病/糖尿病的严格顺序标记。

疾病顺序只有在两个病种的首次观察波次严格先后不同时才记为 `1`。如果同一波次
同时观察到多种疾病，则视为顺序不明确，不强行排序。

## 3. 新增消融

CHARLS 理论基线保留原有 B0-B4，并新增：

| 编号 | 变量 | 用途 |
|---|---|---|
| B3T | B3 静态理论变量和慢病状态 + 共病轨迹特征 | 检验轨迹信息相对静态共病的增量 |
| B4T | B3T 变量 + 随机森林 | 检验轨迹信息是否也能改善非线性模型 |

主要比较：

- `B3 → B3T`：同一逻辑回归下，共病轨迹本身是否带来增量。
- `B4 → B4T`：同一随机森林下，共病轨迹本身是否带来增量。
- `B3 → B4` 与 `B3T → B4T`：分别比较静态模型和轨迹模型的模型族差异。

所有比较继续按 `id` 分组，同一受试者的不同波次不会跨训练折和验证折。

### 当前真实数据结果

2026-11-27 使用现有 CHARLS 标准化表运行 5 折受试者分组验证：

- B3 AUC `0.8272`，B3T AUC `0.8279`；ΔAUC `+0.00074`，
  95% CI `0.00021–0.00121`。
- B3T 相对 B3 的 PR-AUC 增量 `+0.00110`，Brier 降低 `0.00039`。
- B4 AUC `0.8275`，B4T AUC `0.8270`；ΔAUC `-0.00051`，
  95% CI `-0.00147–0.00041`。
- B4T 相对 B4 的 PR-AUC 下降 `0.00166`，Brier 增加 `0.00004`。

结论：轨迹方向在逻辑回归中有极小的统计增量，但没有在随机森林中复现，
幅度也不足以支持“共病轨迹显著提升主模型”的表述。当前保留为研究基线和
后续精确轨迹数据接入接口。

## 4. 防泄漏规则

- 某一行的轨迹特征只能使用该行波次及更早波次的诊断信息。
- 后续波次才出现的新诊断不能回填到早期预测。
- 不能使用完整随访表先算出最终疾病顺序，再合并回所有波次。
- 抑郁标签、CESD 分数、未来波次和受试者 ID 不进入模型特征。
- 同一受试者必须整体落入训练折或验证折。

## 5. 当前局限

当前标准化表只有每轮是否患病的状态，没有原始问卷中的“首次被医生告知”
年龄或年份。因此现有实现应称为“波次观察轨迹”，不能等同于论文中的精确
临床发病轨迹。

论文的方法是观察性时间顺序分析。结果适合表达为“疾病先后关联”或
“转移风险”，不能仅凭条件 Logistic 回归写成已验证的因果关系。

## 6. 组员后续数据交付

后续新增共病数据优先使用“受试者-疾病-时间”长表，最低字段如下：

| 字段 | 类型 | 是否必需 | 说明 |
|---|---|---|---|
| `subject_id` | string | 是 | 与主表一致的脱敏受试者编号 |
| `disease_code` | string | 是 | 使用统一疾病编码 |
| `diagnosed` | 0/1 | 是 | 是否曾经诊断 |
| `onset_age` | number | 推荐 | 首次确诊年龄 |
| `onset_year` | number | 推荐 | 首次确诊年份 |
| `source_wave` | number/string | 是 | 信息来源波次或访视 |
| `confirmed_by` | string | 推荐 | 自报、病历、医生确认等 |

如果继续使用宽表，可使用：

```text
subject_id,wave,wave_date,chronic_hibpe,chronic_hibpe_onset_age,
chronic_arthre,chronic_arthre_onset_age,...
```

模板见 `collaboration/comorbidity/comorbidity_feature_template.csv`。

不得提交真实姓名、身份证号、原始病历、音频或未脱敏 CHARLS 个体数据。

## 7. 组员研究任务

1. 核对论文 14 种疾病的定义与当前 `chronic_*` 字段映射。
2. 整理论文中所有显著疾病对的 OR、95% CI、样本量和方向。
3. 判断哪些数据可以提供首次确诊年龄或年份。
4. 按模板交付脱敏共病轨迹表或字段可用性报告。
5. 对每项新增特征说明医学含义、缺失机制和可能偏倚。
6. 提出 2 到 3 个预先指定的轨迹子组假设，供后续消融验证。

数据接入后先运行特征质量审计，再运行 B3/B3T/B4/B4T。只有在真实验证集
上稳定改善校准或排序指标，才考虑进入主风险模型。
