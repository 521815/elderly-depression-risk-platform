# 数据接入模板

后期拿到正式数据后，不需要改代码。只要把文件放到约定位置，前端和 API 会自动读取。

## CHARLS 标准表

路径：`data/charls_standardized.csv`

必填字段：

```text
id, wave, age, gender, education, marital_status,
self_rated_health, sleep_quality, adl_score, mobility_score,
vigorous_activity, moderate_activity, light_activity,
smoker, drinker, income_earn, income_pension, social_work,
self_memory, immediate_recall, delayed_recall, serial7,
cesd_score, comorbidity_count, depression
```

慢性病字段以 `chronic_` 开头，例如：

```text
chronic_hibpe, chronic_diabe, chronic_cancre, chronic_lunge,
chronic_hearte, chronic_stroke, chronic_psyche, chronic_arthre,
chronic_dyslipe, chronic_livere, chronic_kidneye,
chronic_digeste, chronic_asthmae, chronic_memrye
```

字段约定：

- `depression = 1` 表示抑郁高风险；现有代码用 `cesd_score >= 10` 生成。
- 缺失值保留为空即可，训练时会自动填充。
- `id` 可以是一个人一个 id，也可以带 wave 的 longitudinal 样本 id。

## MPDD 合并特征表

路径：`data/mpdd_features.csv`。工作台“多模态抑郁检测”页会从 `data/mpdd` 的官方 `.npy` 特征自动构建，
也可以通过前端/API 上传到 `data/mpdd_features_uploaded.csv`。

至少需要：

```text
subject_id, label2
```

建议增加：

```text
fold, phq9_score, hamd_score, label3,
neuroticism, extraversion, openness, agreeableness, conscientiousness,
face_* ... audio_* ... gait_* ... personality_* ...
```

模态列名规则：

- 面部特征以 `face_` 开头，例如 `face_AU01_r`, `face_happy`, `face_embedding_0`
- 音频特征以 `audio_` 开头，例如 `audio_opensmile_0`
- 步态特征以 `gait_` 开头，例如 `gait_tsfel_0`
- 人格嵌入特征以 `personality_` 开头，例如 `personality_0`

`label2` 是 MPDD 官方二分类标签，训练、验证和测试必须优先使用该字段。
`phq9_score` 是 PHQ-9 总分；只有 `label2` 缺失时才回退到 `phq9_score >= 8`。
`hamd_score` 是旧接口兼容别名，数值来自 PHQ-9，不代表 HAMD-24。

## 接入方式

1. 准备 CSV。
2. CHARLS 文件直接放到 `data/`，刷新前端即可。
3. MPDD 文件可以放到 `data/`，也可以在 MPDD 页面上传，或调用：

```bash
curl -F "file=@mpdd_features.csv" http://localhost:8001/api/mpdd/upload
```

4. 训练与评估全部通过前端按钮或 API 完成。
