更新日期：2026-09-02

- 项目主页：<https://hacilab.github.io/MPDDChallenge.github.io/>
- GitHub 代码与数据申请说明：<https://github.com/hacilab/MPDD>

## 2 官方申请流程

1. 下载 MPDD Dataset License Agreement PDF。
2. 完整阅读协议，确认理解全部使用规范、限制、责任与义务。
3. 填写协议并由全职教师或研究员手写签署。
4. 将签好的协议扫描件连同姓名、单位、研究方向与用途发送至申请邮箱并抄送通讯作者。
5. 等待数据提供方审核；通过后才会获得已提取特征与标签的访问权限。
6. 使用代码或数据集时引用 MPDD Challenge 论文。

## 3 协议核心义务

依据官方 MPDD Dataset License Agreement，许可为：

- 非独占、不可转让、可撤销、有限许可；
- 仅用于学术研究，不得用于任何商业目的；
- 不得用于商业出版物、报纸或其他公共媒体；
- 不得将数据库整体或部分用于产品销售、推广、面向商业用途的算法训练或商业产品集成；
- 不得以任何形式再分发、公开、复制或传播数据库，包括不得分享、拷贝或向本机构内其他部门/组织分发；
- 未经书面同意不得创建数据库副本，不得再许可或向第三方提供；
- 使用中不得披露个人可识别信息；
- 数据提供方要求时，应允许其对相关处理流程与系统进行合规审计；
- 协议终止后应停止使用并删除全部副本。

## 4 本项目落地方案

### 数据访问

- 项目内数据仅限已签署协议的研究组使用，属于学术科研用途。
- 官方原始特征放在 `data/mpdd/`，聚合表为 `data/mpdd_features.csv` 与 `data/mpdd_utterance_features.csv`。
- 系统界面与 API 仅在本机或本组科研演示环境中使用，不对外提供商用服务。

### 禁止行为

- 不得把 `data/mpdd/`、官方 `.npy` 特征、标签文件或聚合特征表发送给课题组之外的人，也不得放入公开代码仓库、网盘、微信传输或其他共享渠道。
- 不得将 MPDD 特征或其派生数据用于产品化、商业训练、商业部署或公开媒体展示。
- 论文、汇报和前端仅展示聚合统计、图表与模型结果，不附带可识别的原始样本内容。
- MPDD 派生数据（含分模态 Parquet、模拟样本、预测结果和模型权重）同样按协议约束处理，未获书面许可前不对外发布。

### 工程保护

- `.gitignore` 已排除 `data/mpdd/`、MPDD 聚合 CSV/Parquet、预测结果与模型目录，避免误提交。
- 项目代码若公开发布，应先确认不含上述数据与派生文件，并在 README 或数据可用性声明中写明“MPDD 数据不随代码发布，需按官方流程申请”。
- 内部复制或移交项目时，只移交代码、文档、聚合统计与图表；需要移交 MPDD 数据时，先取得数据提供方书面同意。

### 授权状态

- 本项目 MPDD 数据由大创导师（全职教师/研究员）按官方流程申请获得，2026-09-02 经用户确认。
- 申请材料、签署文件与邮箱回执由导师或课题组保密保存，项目目录不收录。
- 论文与代码仅按学术研究范围使用 MPDD，若后续准备商用或对外部署，须先咨询数据提供方是否需要单独授权。
