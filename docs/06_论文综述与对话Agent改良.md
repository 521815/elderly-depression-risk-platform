# 论文综述与对话 Agent 改良

## 1. 已学习的关键论文

### 1.1 CHARLS 共病与抑郁风险建模

- Zhang 等，BMC Public Health 2025，`10.1186/s12889-025-23075-7`
  - 使用 CHARLS 2018-2020 中老年心血管代谢疾病患者，先 LASSO 筛变量，再比较 LR/RF/XGBoost。
  - 关键变量：年龄、性别、教育、居住方式、生活满意度、乐观程度、自评健康、慢性病与功能受限。
  - 对本项目启示：人口学与共病不能只看“有几个病”，还应纳入自评健康、社会支持、生活满意度、功能状态。

- Han 等，Journal of Health, Population and Nutrition 2025，`10.1186/s41043-025-00897-0`
  - 用社会与环境健康决定因素预测中老年心血管-肾脏-代谢综合征患者抑郁风险。
  - 使用 Coxph、Ridge、Lasso、RF、XGBoost、GBM、神经网络，并用 SHAP 解释。
  - 对本项目启示：模型层应保留可解释性和概率校准，输出不应只有“是否抑郁”，还要有风险因子排序。

### 1.2 老年人抑郁的多模态检测

- Wang 等，ACM Multimedia Asia 2025，`arXiv:2510.08004`
  - 音频模态融合 LLD、MFCC、Wav2Vec；视频模态融合 OpenFace、ResNet、DenseNet。
  - 设计人格-多模态交互模块，利用 Big Five 人格作为辅助信号。
  - 对本项目启示：MPDD 不应只做后期平均融合，后期可以补人格/共病条件化模块。

- Fu 等，MPDD-AVG 2026
  - 融合半结构化访谈的音视频线索和穿戴式 IMU 步态。
  - 特别说明 MPDD-Elderly 研究的是“慢性病和生活安排影响下的晚年抑郁”，因此慢病、居住状态、步态节律应进入最终特征。

### 1.3 老年对话式 AI 与 LLM

- “Could a phone call to an AI simplify measurement-based care for older adults”
  - 提出 AI 语音访谈应动态调整追问，而不是逐条读量表；既采集标准化评分，又获取更丰富的患者故事。
  - 对本项目启示：访谈不能是固定问题轮播，而要按回答内容触发追问、澄清和总结。

- Nawaz 与 Ahmad，“Conversational AI for Cognitive, Emotional, and Social Engagement of Elderly Persons”
  - 架构包括对话管理器、记忆增强交互、嵌入式认知评估、情感分析和照护者看板。
  - 对本项目启示：Agent 需要“访谈状态机 + 短时记忆 + 风险线索抽取 + 照护者侧解释”。

- 韩国农村 CareCall 研究，BMC Geriatrics 2026
  - AI 电话对话可以观察老年人抑郁情绪线索；需要关注低响应、简答、回避、负面表达等模式。
  - 对本项目启示：不只是“说了负面词”，还要把“过度简短、反复说身体不舒服、不愿谈情绪”作为行为风险线索。

## 2. 改良后的访谈 Agent 设计

### 2.1 访谈主题

Agent 按临床访谈维度覆盖，但提问顺序会根据回答动态调整：

1. 睡眠与精力
2. 兴趣与愉悦感
3. 情绪与悲伤
4. 躯体不适与共病负担
5. 认知与注意
6. 社交与孤独
7. 无望、自责与价值感
8. 安全风险与求助意愿

其中“安全风险”一旦出现，优先进行共情、确认安全、给出求助渠道，不再机械追问。

### 2.2 自适应追问策略

- 用户谈到某个主题时，Agent 先复述并共情，再在该主题内追问细节。
- 若回答仍模糊，才进入下一主题；若回答信息足够，则标记该主题已覆盖。
- 已覆盖 6-7 个主题后，Agent 做小结，并邀请用户补充最困扰的问题。
- 每次回复都会从用户表达中抽取风险线索，供风险页展示。

### 2.3 LLM 可选增强

输入 `OPENAI_API_KEY` 或侧边栏 API Key 时，Agent 可调用 OpenAI 生成更自然的共情回复，并通过 JSON 返回回复、下一问题与风险线索；失败时自动回退到本地规则访谈器，保证可用性。

### 2.4 安全边界

Agent 只在科研筛查范围内进行共情访谈，不诊断、不治疗。检测到自伤/自杀相关表达时，会明确提示联系精神卫生热线或家属/医务人员。

## 3. 最终风险构成的权重依据

最终抑郁概率由多个风险信号加权求和：

```text
有 MPDD 多模态结果时：
  文本 15% + 量表 30% + 背景/共病 20% + 表情 10% + MPDD 25%

无 MPDD 多模态结果时：
  文本 20% + 量表 40% + 背景/共病 20% + 表情 20%
```

### 3.1 量表权重最高

GDS-15 的元分析显示，在老年人中 pooled sensitivity 约 86%、specificity 约 79%，AUC 约 0.90（PMID 31881393）；PHQ-9 在老年人群的筛查性能同样稳定。量表是目前证据强度最高、最可重复的风险信号，因此无 MPDD 时给 40%，有 MPDD 时仍保留 30%。

### 3.2 多模态信号：语音/面部/步态/人格

MPDD 相关研究（arXiv 2505.10034 官方 Challenge、arXiv 2510.08004）一致表明，融合语音、面部、步态和人格的多模态模型优于单模态。Aharonson 等 2025 年发表于 Current Directions in Biomedical Engineering 的研究进一步显示，语音声学特征对抑郁判别的贡献约为文本的 3:1。因此本项目把语音/面部等直接观察证据统一放进 `MPDD` 信号，有该结果时给 25%，并把表情单独保留 10%。

### 3.3 背景/共病证据

基于 CHARLS 的研究显示，1 种慢性病与老年抑郁风险 OR 约 1.20，多病时 OR 约 1.55，部分研究在 2 种及以上慢病时达到 OR 2.34（PMC10020227 等）。年龄、性别、婚姻状况和居住安排也是 CHARLS 建模中的常见预测变量。因此背景/共病固定给 20%，不在最终融合里进一步放大。

### 3.4 文本线索权重

对话文本用于捕捉负面表达、睡眠/兴趣/躯体/无望/自责等线索。单模态文本在 MPDD 系列实验中不是最强信号，因此没有 MPDD 时给 20%，有 MPDD 时让出 5% 给多模态，保留 15%。

### 3.5 说明

以上权重属于“文献先验权重”，用于把已有研究证据转成可解释的筛查分数，并非本项目数据学出来的回归/校准权重。后续接入完整数据后，建议用验证集做 Stacking、Isotonic 校准或逻辑回归权重学习，再替换这些先验值。

已实现的学习型替代方案：`scripts/07_train_fusion.py` 与工作台“融合校准”页会把“信号概率 + 标签”数据训练成逻辑回归融合模型，保存到 `output/fusion_models/fusion_weights.json`。训练完成后，风险评估页会自动优先使用学习权重，未训练时仍回退到本节文献先验权重。
